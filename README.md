# LinkShortener

LinkShortener — это простой сервис для сокращения ссылок. Он позволяет пользователям создавать короткие ссылки для длинных URL и управлять ими.

## Как пользоваться сервисом

1. **Запустите проект**:
   - Откройте проект в IntelliJ IDEA.
   - Убедитесь, что у вас установлен JDK (Java Development Kit) 11 или выше.
   - Запустите класс `Main.java`, чтобы запустить сервис.

2. **Использование сервиса**:
   - Введите оригинальный URL, который вы хотите сократить.
   - Введите лимит переходов для сокращенной ссылки.
   - Сервис сгенерирует короткую ссылку, которую вы сможете использовать.

3. **Выход из программы**:
   - Чтобы выйти из программы, введите `exit`.

## Поддерживаемые команды

- Ввод оригинального URL: вводите полный URL, который вы хотите сократить.
- Ввод лимита переходов: вводите целое число, определяющее максимальное количество переходов по сокращенной ссылке.
- Команда выхода: введите `exit`, чтобы завершить работу сервиса.

## Описание классов

- **Link**: 
  - Представляет собой сокращенную ссылку, содержащую оригинальный URL, короткий URL, лимит переходов, время истечения и счетчик переходов.
  
- **User **: 
  - Представляет пользователя, который может иметь несколько сокращенных ссылок. Содержит список ссылок, созданных пользователем.
  
- **LinkService**: 
  - Обрабатывает логику сокращения ссылок и перенаправления. Управляет пользователями и их ссылками.
  
- **NotificationService**: 
  - Обеспечивает отправку уведомлений пользователям (в текущей реализации выводит уведомления в консоль).
  
- **Config**: 
  - Загружает конфигурационные параметры из файла `config.properties` (например, время жизни ссылки и лимит переходов по умолчанию).
  
- **Main**: 
  - Точка входа в приложение. Обрабатывает ввод пользователя и взаимодействует с сервисом.
